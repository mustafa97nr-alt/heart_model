# Heart Echo AI

Deep learning framework for heart disease classification using echocardiography.

## Research Goal

The goal of this project is to develop an artificial intelligence model for analysis and classification of heart diseases from echocardiography images or videos.

## Initial Models

- EfficientNet
- ResNet50
- ConvNeXt
- Video deep learning models

## Initial Datasets

- EchoNet-Dynamic
- CAMUS
- TMED
